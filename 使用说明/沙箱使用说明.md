# Linux 沙箱使用说明

Linux 沙箱是给 Agent 用的一个隔离的小环境。Agent 可以在里面运行命令和 Python 脚本，帮你处理文件，不用为此专门开一台 Windows 虚拟机。

## 一、它适合做什么

- 读取和解析 PDF、Word、Excel、PowerPoint，提取文字和表格；
- 转换文件格式、批量处理文件、压缩和解压；
- 用 Python 计算、画图、整理数据；
- 从互联网下载文件，或安装需要的 Python 包；
- 运行标为「沙箱」的技能里的脚本（技能页面上能看到每个技能在哪里运行）。

需要 AutoCAD、SolidWorks、ANSYS 等工程软件，或者要操作 Windows 界面、录制操作轨迹的工作，仍然在虚拟机里做。

你不用专门交代，Agent 会自己判断什么时候用沙箱。想让它用，也可以直接说，例如"用沙箱里的 Python 把这个 PDF 里的表格整理成 Excel"。

## 二、沙箱里能看到哪些文件

| 沙箱里的位置 | 是什么 | 能不能改 |
| --- | --- | --- |
| `/workspace` | 本任务的文件（虚拟机里的 D 盘） | 能改；任务完成后只读 |
| `/shared` | 项目公共空间（虚拟机里的 F 盘） | 能改 |
| `/inputs/任务编号` | 已完成的上游任务的结果 | 只读 |
| `/tasks/任务编号` | 本项目所有任务的文件 | 只读 |
| `/skills` | 全局技能库（项目技能在 `/shared/skills`） | 只读 |
| `/plugins` | 已安装的插件（插件里的技能） | 只读 |

Agent 写到 `/workspace` 或 `/shared` 的文件，会马上出现在文件面板和虚拟机里。项目对话（不属于某个任务的对话）没有 `/workspace`，默认在 `/shared` 下工作。

## 三、安全

- 每个对话有自己的沙箱，彼此看不到对方的临时文件。
- 沙箱可以上公网（网页和下载），但**不能访问局域网、Studio 本身和虚拟机**。
- 沙箱运行在隔离层（gVisor）里，里面的程序碰不到服务器本身。
- 任务完成后，这个任务的沙箱会立即被结束，之后沙箱里的 D 盘只读。
- Agent 在沙箱里运行的每条命令都记在操作日志里，导出项目时一起导出。

## 四、闲置回收

- 沙箱在 Agent 第一次使用时自动启动，需要几秒钟。
- 一段时间没有运行命令（默认 30 分钟），沙箱会被停止。D 盘、F 盘里的文件都保留；沙箱里 `/tmp` 的临时文件和装过的 Python 包会被清掉，下次需要时 Agent 会重新安装。

## 五、设置

点左下角 **模型配置**，往下找到 **Linux 沙箱**：

- **允许 Agent 使用 Linux 沙箱**：关掉后 Agent 就不能再用沙箱，正在运行的沙箱会被结束（文件不受影响）。
- **每个沙箱的 CPU 核数**、**每个沙箱的内存（GB）**：一个沙箱最多能用多少。
- **最多同时运行的沙箱数**：满了以后，新的对话要等别的沙箱闲置回收后才能用。
- **闲置多久后回收（分钟）**。

点 **保存沙箱设置** 后立即生效。改了 CPU 或内存的话，正在运行的沙箱会在下一次运行命令时按新的上限重新启动，装过的包要重装。能填的最大值由服务器决定，页面下方会写出来。

标题右边显示沙箱服务的状态和正在运行的沙箱数。如果显示"连不上"或"没有安装"，请联系管理员。

## 六、常见问题

- **Agent 说沙箱数量已达上限**：稍后再试，或在设置里调大"最多同时运行的沙箱数"。
- **下载失败**：沙箱只能访问公网的网页和文件（http/https）。局域网地址（例如 `10.x.x.x`、`192.168.x.x`）会被拒绝，这是有意的。局域网里的文件请先放进任务文件或项目文件里。
- **技能页面提示「Linux 沙箱已在设置里关闭」或「本部署没有安装 Linux 沙箱」**：标为沙箱的技能这时不能运行，Agent 会直接告诉你。打开设置里的开关，或联系管理员安装。
- **命令被中途结束**：一条命令默认最多运行 5 分钟，Agent 可以按需延长到 30 分钟；用的内存超过上限也会被结束。
