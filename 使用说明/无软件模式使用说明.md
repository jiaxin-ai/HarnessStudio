# 没有虚拟机时的 HarnessStudio（无软件模式）使用说明

有些机器上没有装虚拟机平台（vm_manager），比如你把 HarnessStudio 装到自己的服务器上。这时 Studio 照常能用，只是**不能用工业软件**：没有 AutoCAD、SolidWorks、ANSYS 这些软件，也没有虚拟机。Agent 改用文件、Linux 沙箱和联网来完成任务。

部署时如果没有找到虚拟机平台，`harnessstudio` 会自动这样设置，你不用做什么。

## 一、和有虚拟机时有什么不同

| 有虚拟机 | 没有虚拟机 |
| --- | --- |
| 任务页右下角有「任务文件」「项目文件」「软件」三个标签 | 只有「任务文件」「项目文件」，没有「软件」 |
| 可以开虚拟机、录屏、看操作轨迹 | 没有这些功能 |
| 文件叫“D 盘”“F 盘” | 叫“任务文件”“项目公共空间” |
| 自主模式里可以设“同时开的虚拟机” | 没有这一项 |

其他功能都一样：项目、任务图谱、对话、文件、沙箱、技能、MCP 工具、插件、自主模式、导出。

## 二、文件放在哪里

- **任务文件**：每个任务自己的文件。在任务页「任务文件」里看和改。
- **项目公共空间**：整个项目共用的文件，比如资料、图纸、参数表。在「项目文件」里上传、新建、编辑。项目技能放在它的 `skills` 文件夹里。
- 清空任务会删掉这个任务的文件，删除任务或项目会把文件一起删掉。需要的文件请先下载保存。

## 三、Agent 能做什么

- 读写任务文件和项目公共空间。
- 在 Linux 沙箱里跑命令和 Python 脚本：算数、画图、处理表格、转换和检查文件格式（例如 DXF、STL、CSV），从网上下载资料（沙箱的开关在「模型配置」页的「Linux 沙箱」）。
- 联网搜索和阅读网页、PDF。
- 使用技能。标成“在虚拟机里运行”的技能在这里不能运行，页面上会写明。

Agent 知道这里没有工业软件。必须用专业软件才能做的步骤，它会写明需要什么软件、要做什么，把准备好的输入整理成文件，交给你在有软件的环境里处理，不会假装做过。

## 四、以后接入虚拟机

**接不接虚拟机，第一次部署时就要定下来，之后不要切换。** 两种模式把任务文件放在不同的地方，部署以后再切换，原有项目的任务文件在网页上就看不见了；`harnessstudio` 发现这种切换会拒绝部署，什么都不改。想要一个接虚拟机的 Studio，请另起一个实例：在另一个文件夹再解压一份安装包，第一次用 `HS_INSTANCE=新名字 ./bin/harnessstudio` 启动，端口换一个，第一次的问题里填上 vm_manager 的地址。步骤见安装包里 `安装说明.md` 第五节的「另起一个实例」。现在这个没有虚拟机的实例和它的项目照常留着。
