# 插件使用说明

插件就是一个打包好的文件夹，里面可以放好几个技能和 MCP 服务。装一次，所有项目都能用，不用一个个添加。

插件的格式和 Claude Code 的插件一样，别人给 Claude Code 做的插件，大多可以直接装进来。

## 一、安装插件

点左下角 **插件**，有三种方法：

1. **上传文件夹**：选中整个插件文件夹。
2. **上传 ZIP**：插件文件夹打成的 ZIP 包。
3. **拖进来**：把插件文件夹或 ZIP 直接拖到列表里。

一个插件最多 50 MB、2000 个文件；ZIP 包本身最多 20 MB、1000 个条目，更大的插件请上传文件夹。已经有同名插件时，会先问你要不要替换；替换后原来的开关和设置都保留。

**另一种方法**：直接把插件文件夹复制到 Studio 数据目录下的 `plugins` 文件夹里（线上是数据卷里的 `studio/plugins/`），几秒钟后插件页面就会出现它。改动或删除这个文件夹，也会自动生效。

## 二、插件里能放什么

```
cad-tools/                      ← 插件文件夹
├── .claude-plugin/
│   └── plugin.json             ← 插件的名称和简介
├── skills/                     ← 技能，每个技能一个文件夹
│   ├── gear-calc/SKILL.md
│   └── step-export/SKILL.md
└── .mcp.json                   ← MCP 服务
```

`plugin.json` 最少写一个名称：

```json
{
  "name": "cad-tools",
  "displayName": "CAD 工具包",
  "description": "齿轮计算和 STEP 导出",
  "version": "1.0.0"
}
```

- **name**：只能用小写字母、数字和连字符。没有 `plugin.json` 时，用文件夹的名字当插件名。
- **skills/**：技能的写法和技能页面的一样，见《技能使用说明》。
- **.mcp.json**：MCP 服务的地址，写法见下面第四节。

## 三、启用、停用和删除

- 每个插件一行，右边的开关管整个插件：关掉后，它的技能和 MCP 工具 Agent 都看不到了，但不会删除。
- 点 **查看** 能看到插件里有哪些技能、每个技能在哪里运行、MCP 服务连上没有。
- 点 **删除** 会删掉整个插件文件夹，不能恢复。
- 改动从下一条消息开始生效。

插件的技能和 MCP 服务，在 **技能** 和 **MCP 工具** 页面的“来自插件”一栏里也能看到，但要在插件页面管理。

## 四、插件里的 MCP 服务

`.mcp.json` 的写法：

```json
{
  "mcpServers": {
    "gears": {
      "type": "http",
      "url": "http://<服务器地址>:8765/mcp",
      "headers": { "Authorization": "Bearer ${user_config.api_token}" }
    }
  }
}
```

- 只接入 `"type": "http"` 的服务，也就是 Studio 能通过网络直接访问的服务。
- 需要在本机启动程序的那种（写着 `command`，例如 `npx ...`），页面上会显示“暂不支持”。

**需要密钥的服务**：在 `plugin.json` 里声明一个设置项，在 `.mcp.json` 里用 `${user_config.名称}` 引用它：

```json
"userConfig": {
  "api_token": { "type": "string", "title": "服务密钥", "description": "找信息部要", "sensitive": true, "required": true }
}
```

装好以后，插件那一行会提示“还要填写设置”。点 **设置** 填上就行。`sensitive: true` 的值保存后不会再显示，留空就继续用原来的。

**名字重复时**：如果 MCP 工具页面里已经有同名的服务，或者另一个插件先用了这个名字，这个服务不会接入，页面上显示“名称冲突”。

## 五、技能重名时

项目技能 > 全局技能 > 插件技能。同名的话，前面的优先。被盖住的插件技能，页面上会写明。

## 六、目前不支持的内容

这些内容插件页面会列出来，并且不会加载：

- Hooks（`hooks/`）
- 命令（`commands/`）
- 子 Agent（`agents/`）
- 可执行文件（`bin/`）
- LSP、输出风格等其他内容
- 需要在本机启动程序的 MCP 服务

另外，**虚拟机看不到插件里的技能**。要在虚拟机里运行的脚本，请放到项目技能里，见《技能使用说明》第五到七节。
