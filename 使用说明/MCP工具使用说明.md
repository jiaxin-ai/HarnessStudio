# MCP 工具使用说明

MCP 服务是别人写好、在网络上提供工具的程序，例如某个数据库、知识库或在线服务的 MCP 服务。接上以后，Agent 就能直接调用它提供的工具。

这里只接 **Studio 能直接访问的外部服务**。要在虚拟机里操作工程软件，不用 MCP，而是把脚本做成项目技能，由 Agent 在虚拟机里运行（见《技能使用说明》第五到七节）。

## 一、添加

1. 点左下角 **MCP 工具** → **添加 MCP 服务**。
2. 填 **名称**（字母、数字、- 和 _，例如 `materials`）和 **地址**（服务说明里的 HTTP 地址，通常以 `/mcp` 结尾，例如 `http://<服务器地址>:8765/mcp`）。
3. 服务需要密钥的话，点 **添加请求头**，例如名称填 `Authorization`，值填 `Bearer 你的密钥`。
4. 点 **测试连接**。显示"连接成功，提供 N 个工具"就点 **保存**。

保存后马上生效，不用重启，所有对话里的 Agent 都能用这些工具。

## 二、日常管理

- **已连接 · N 个工具**：正常。点"查看工具"能看到每个工具是做什么的。
- **连接失败**：下面会写原因，常见的是服务没启动、地址或端口写错、密钥不对。修好服务后点 **重新连接**。
- 暂时不想让 Agent 用，把开关关掉；不再需要就 **删除**。
- 密钥保存后不会再显示。编辑时密钥那一栏留空，就继续用原来的。

## 三、在对话里

不用做什么。Agent 会根据工具说明自己决定什么时候调用。对话里工具卡片显示为"名称 · 工具名"，例如"freecad · make_box"，点开能看到参数和结果。

## 四、目前的限制

- **不要把 MCP 服务装在虚拟机里。** 虚拟机对外只开放画面、远程桌面和内部控制用的几个端口，而且每次开机端口号都会变，Studio 连不上虚拟机里的服务。要在虚拟机里操作软件，请做成项目技能里的脚本。
- 需要 Studio 自己启动一个本地程序的那种（说明里写 `npx ...` 或 `python ...` 的）暂不支持。
- 请求头的值只能用英文字母、数字和符号，不能有中文。
- 插件里也可以带 MCP 服务，它们显示在本页的“来自插件”一栏，在插件页面管理（见《插件使用说明》）。
- MCP 服务对所有项目都可见，暂时不能只给某个项目用。
