# 后台运行使用说明

有些命令要跑很久，比如求解、重建模型、批量导出。Agent 在虚拟机里执行普通命令时最多等 110 秒，超过就会被结束。这类长命令，Agent 会改用**后台运行**：命令在虚拟机里一直跑，Agent 隔一会儿查一次进度，跑完再继续。

## 一、你会看到什么

- 对话里，Agent 启动后台任务后会拿到一个任务号（例如 `job-3f2a9c1d0b7e`），之后定期汇报进度。
- 软件区：有后台任务在运行时，状态栏会显示 **后台任务 N 个运行中**，点它打开 **⋯ 详细信息**，可以看到这台虚拟机上的后台任务：命令、开始时间、状态、返回码。
- 任务文件里会多出一个 `.studio-jobs` 文件夹，旁边标着「后台运行日志 · 自动清理」。每个后台任务一个子文件夹：
  - `stdout.txt`：命令的正常输出；
  - `stderr.txt`：命令的错误输出；
  - `job.json`：状态记录。

  命令运行时，这些文件随时在变，你可以随时打开看、下载。它们由虚拟机写入，在任务文件面板里**只能看，不能编辑、上传、改名或删除**。
- `stdout.txt` 和 `stderr.txt` 每个最多 10 MB。输出超过 10 MB 时，前面的部分会被删掉，只保留最后一段，文件第一行会写明删掉了多少。

## 二、停止后台任务

在 **⋯ 详细信息** 的后台任务列表里，点那一条的 **停止…**，确认后会结束这个命令启动的全部程序。已经写出的输出会保留。

Agent 也可以取消后台任务，但只能取消它在这个对话里启动的，而且应该先征得你同意。

## 三、状态是什么意思

| 状态 | 意思 |
| --- | --- |
| 运行中 | 还在跑 |
| 已结束 | 命令自己跑完了，看返回码判断成功与否（一般 0 是成功） |
| 已取消 | 你或 Agent 停止了它 |
| 超时结束 | 超过了 Agent 设定的最长时间（默认 60 分钟，最长 24 小时），已被结束 |
| 中断 | 跑的过程中虚拟机停止、失败，或 Windows 重启了（包括自动续期授权时的那次重启） |
| 结果未知 | 暂时或永远无法确定结果，例如虚拟机内的服务暂时没响应 |
| 未能启动 | 命令根本没有跑起来 |

**中断、结果未知、未能启动的任务都不会自动重跑。** Agent 会告诉你情况，由你决定要不要再跑一次。

## 四、需要注意的

- **你点"我来操作"接管虚拟机时，后台任务会继续跑。** 如果后台任务正在操作某个软件（例如 SolidWorks），你同时在画面上操作同一个软件，可能会互相干扰。
- **停止虚拟机、续期授权（会重启 Windows）、确认完成任务，都会中断正在跑的后台任务。** 确认框里会提示有几个后台任务会被中断。
- 后台任务最长只能跑到虚拟机的到期时间。要跑更久，先在软件区点 **延长 1 小时**，或者在详细信息里改运行时长。
- 每台虚拟机最多同时跑 3 个后台任务。
- 下次启动后台任务时，`.studio-jobs` 里结束超过 7 天的文件夹会被自动删除；已结束的文件夹超过 30 个时，也只留最近的 30 个。正在跑的不会被删。
- 日志不算工作成果：不会出现在完成任务时的文件列表里，不会进入完成快照，也不能作为提交文件或验收证据。要交付或长期保留的结果，请让 Agent 另存到任务文件的其他位置。
