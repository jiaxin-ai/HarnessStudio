# Agent 看图使用说明

Agent 现在可以直接“看”文件里的图片，例如题目给的草图截图、照片、扫描的图纸。以前它只能看到“这是一个二进制文件”，要绕很多路（开虚拟机全屏显示再截图、在沙箱里量像素），又慢又费 token。

## 一、前提：模型要支持图片

在对话里选一个支持图片的模型（模型设置里标着“支持图片”，例如 deepseek-flash）。

不支持图片的模型（例如 deepseek-v4-pro）看不到图，只能知道图片的尺寸和格式，它会告诉你需要换模型或请你帮它看。

## 二、能看哪些地方的图片

| 位置 | 说明 |
| --- | --- |
| 本任务的文件 | 虚拟机里的 D 盘；也包括本任务的完成快照和上游任务交来的结果 |
| 项目共享盘 | 虚拟机里的 F 盘，批量任务清单里的输入文件就放在这里 |
| 同项目其他任务的文件 | 只读，看不到别的项目 |
| 本对话的临时文件 | 例如 Agent 下载的图片、保存下来的截图 |

项目对话（含自主模式的总 Agent）没有“当前任务”，所以能看共享盘、各任务的文件和自己的临时文件。

支持的格式：PNG、JPEG、WebP、GIF（只看第一帧）、TIFF。

**看局部**：图上的小字、尺寸标注看不清时，Agent 可以只看图的一块，这一块会尽量放大。

## 三、看不了什么

- **PDF**：不是图片。Agent 会先在沙箱里把它转成图片（PNG），存进任务文件，再看。
- **CAD 和工程文件**（DXF、DWG、SLDPRT、STEP 等）：不是图片。Agent 会在虚拟机的软件里打开它，导出图片或截图再看。没有接软件的部署里，请你提供导出的图片。
- **其他图片格式**（BMP、SVG 等）：Agent 会先在沙箱里转成 PNG。
- **太大的图片**：单张超过 10 MB、4000 万像素或单边 12000 像素时，Agent 只能看其中一块，或者先在沙箱里把图缩小。
- 别的项目的文件、其他对话的临时文件，Agent 都看不到。看图不会让它读到原来读不到的文件。

## 四、在对话里看到 Agent 看过的图

Agent 每看一张图，对话里那一步的工具卡片下面会出现这张图的缩略图，点开是大图。虚拟机截图也一样显示。导出项目时，对话记录（`chat.json`）里记着 Agent 看了哪张图、原图多大。

## 五、看图会多用一些 token

- 一张图大约相当于 200～1000 个 token（大图约 1000，看局部或小图更少）。
- 图片看过之后会留在对话里，之后每一步都会再带上它（按“缓存读取”计费，自主模式的预算按折算值算），直到对话变长、旧内容被压缩成摘要为止。

所以 Agent 被要求：看清需要的信息后，把读到的内容写成文字（例如写进任务文件），不要反复看同一张大图。如果你发现它反复看同一张图，可以提醒它先把内容记下来。
