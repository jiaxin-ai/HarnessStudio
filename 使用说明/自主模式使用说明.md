# 自主模式使用说明

平时在 HarnessStudio 里，是你和 Agent 一起做事：你确认需求、勾选清单、确认任务完成。**自主模式**换一种做法：你写下一个目标，Agent 自己把整件事做完——自己规划任务、派人去做、检查结果、确认完成，只在必须由你出面时才停下来。

## 一、它适合做什么

- 目标清楚、步骤多、可以拆成很多小任务的工作，例如"完成减速器箱体的建模、校核，出装配图和报告"；
- 互不依赖的任务可以同时做，比一个对话一步步做快；
- 你不想一直盯着，希望 Agent 做完再来抽查。

不太适合：需求还很模糊、需要你边做边想的工作。这类工作先在项目对话里和 Agent 把需求聊清楚，再启动自主模式。

## 二、谁在干活

- **总 Agent**：理解你的目标，在任务图谱里规划任务，安排谁先做谁后做，跟进进度，最后判断目标是否达成。
- **子 Agent**：每个子 Agent 负责一个具体任务，和你平时在任务页里对话的 Agent 一样：能读写任务文件、开虚拟机、用沙箱、上网、用技能。互不依赖的任务会有几个子 Agent 同时做。

总 Agent 和子 Agent 都有自己的对话，你随时可以打开看，也可以在对话里插话。对话标签上会标着「总 Agent」或「子 Agent」。

## 三、怎么启动

在项目页（或任务页）右上角点 **自主模式**，在弹出的窗口里填：

1. **目标**：写清楚要做成什么、做到什么程度、有什么要求和限制。目标越具体，Agent 越少停下来问你。例如：

   > 完成减速器箱体的三维建模和强度校核，输出装配图（DWG）和校核报告（PDF）；材料用 HT200，安全系数不低于 1.5，箱体壁厚 8 mm。

   缺关键信息时，Agent 会在对话里问你。

2. **范围**：
   - **整个项目**：总 Agent 可以规划和完成项目里的全部任务；
   - **只做某个任务分支**：先在图谱里选中一个任务，总 Agent 只在这个任务和它下面的子任务里工作，不会动其他任务。

3. **模型**：
   - **总 Agent**：建议选能力强的模型；
   - **子 Agent（默认）**：做具体任务默认用的模型；
   - **总 Agent 还可以给个别任务换用**：勾选其他模型，总 Agent 可以给特殊的任务换用。比如要操作虚拟机里的软件，需要一个**支持图片**的模型，子 Agent 才能看到屏幕。所选模型都不支持图片时，窗口里会提醒你（不加也能启动）。

   窗口会记住你上次选的模型。

4. **预算**：预先填好了默认值，这次可以单独改，见第八节。

点 **开始运行**。一个项目同时只能有一个自主运行。

## 四、运行中能看到什么

- 右上角的按钮变成 **自主模式 · 运行中**（或"等待你处理""已暂停"等），点它打开**运行面板**。
- 左侧项目列表里，这个项目旁边有一个小标记：「自主」表示正在运行，橙色的「待处理 N」表示有 N 件事等你处理。
- 任务图谱里：
  - 有子 Agent 在做的任务标着 **Agent 工作中**（子 Agent 在等你时标着 **Agent 等你处理**），任务组上会写"N 个子任务有 Agent 在做"；
  - 由 Agent 确认完成的任务标着 **Agent 完成**，和你自己确认完成的任务区分开。
- 对话里，总 Agent 发给子 Agent 的话显示为 **总 Agent 的指令**，系统发出的进度通知显示为 **自主运行通知**，都不会显示成你说的话。

运行面板里有：

| 部分 | 内容 |
| --- | --- |
| 状态 | 现在在做什么、为什么暂停；「总 Agent 对话」「暂停」「继续」「停止」按钮 |
| 需要你处理 | 等你处理的事情，每件都有跳转和处理按钮（见第五节） |
| 目标 | 这次的目标；可以点「修改目标、模型和预算」 |
| 预算用量 | 折算 token、时长、总 Agent 轮数、虚拟机、子 Agent 各用了多少；用到 80% 以上会变成橙色并写"接近上限"。折算 token 下面一行写着它是怎么算出来的（未缓存输入、缓存读取、缓存写入、输出各多少） |
| 子 Agent | 每个子 Agent 做哪个任务、用什么模型、现在的状态、最近一次报告和活动时间。点一行就跳到那个任务和它的对话 |
| 最近发生的事 | 派出、完成、报告、需要人等事件，点击可以跳过去 |

运行面板在右侧，不挡住图谱和对话，你可以一边看面板一边点进各个任务。按 Esc 或右上角的 × 关闭。窄屏上面板占满屏幕，点进任务后会自动收起。

## 五、什么时候会停下来等你，怎么处理

只要有一件事等你处理，状态就是"等待你处理"。**与这件事无关的子 Agent 照常工作。**

| 情况 | 你会看到 | 怎么处理 |
| --- | --- | --- |
| Agent 缺关键信息 | 「Agent 在问你问题」 | 点 **去回答**，在对话里回答它的问题 |
| 需要你动手（登录、许可证、弹窗、软件授权等） | 「需要你动手处理」 | 点 **打开对话** 看清楚要做什么，处理好后在对话里回复它，或点 **我已处理好**。不想让它再做了，点 **停止这个子 Agent** |
| 子 Agent 好像卡住了（反复失败，或连续几轮没有进展） | 「子 Agent 好像卡住了」 | 点 **查看对话** 了解情况；可以在对话里给它明确的指示，或点 **让它继续**、**停止这个子 Agent** |
| 预算用完 | 「预算用完」，运行自动暂停 | 点 **调整预算** 调高，再点 **继续运行**；或者停止运行。预算没调高就继续，会提示你先调高 |
| 服务重启过 | 「服务重启过」，运行自动暂停 | 点 **继续运行**，Agent 接着做 |
| 总 Agent 停了下来（模型调用出错、回复太长被截断，或它所在的任务被清空、删除） | 「总 Agent 停了下来」，运行自动暂停 | 点 **查看对话** 看看发生了什么，再点 **继续运行**；或者停止运行 |
| 总 Agent 认为目标已达成，但还有任务没做完 | 「总 Agent 认为目标已达成，但还有任务没做完」，下面列出没完成的任务和总 Agent 的理由 | 见下面 |

**目标已达成、但还有任务没做完时**，总 Agent 不会自己结束，而是停下来让你决定：

- **让它继续做**：总 Agent 接着把这些任务做完。
- **接受，结束运行**：你同意它的理由（比如有些任务确实不需要单独做），运行结束并标为已完成。没做完的任务保持原样，以后你可以自己做，或再启动一次自主运行。点这个按钮会再确认一次。

列表里的任务可以点击，先去看看再决定。这件事没处理之前，运行面板上的「继续」不起作用，要在这里二选一。

## 六、暂停、继续、停止

| 操作 | 会发生什么 | 之后 |
| --- | --- | --- |
| **暂停** | 不再派出新的子 Agent；总 Agent 和子 Agent 手上的这一步停下。**虚拟机不会关**（它们有自己的运行时长上限） | 点 **继续**，接着做 |
| **继续** | 总 Agent 收到通知，接着规划和派活；停下的子 Agent 由总 Agent 决定是否让它继续 | — |
| **停止** | 这次运行结束，不能再继续。所有 Agent 停下手上的工作 | 已完成的任务、文件和对话都保留；没完成的任务保持现在的样子 |

停止前会再确认一次。总 Agent 报告"目标受阻"时，运行状态是"受阻"，你处理好问题后可以点 **继续**，也可以停止。

在对话里点停止按钮也可以：在**总 Agent 的对话**里点停止，等于暂停整个运行；在**子 Agent 的对话**里点停止，只停下它手上这一步，它仍然负责这个任务。

点暂停、继续、停止时，如果提示"运行刚刚有了变化"，说明运行在这一两秒里自己变了（例如预算用完自动暂停了）。面板已经显示最新状态，看一下再操作一次就行。

运行中你可以随时**修改目标、模型和预算**（运行面板里的「修改目标、模型和预算」），也可以像平时一样改图谱和清单，总 Agent 会收到通知并按新的情况调整。模型这里可以换子 Agent 的默认模型，也可以勾选“总 Agent 还可以给个别任务换用”的模型；总 Agent 自己的模型运行开始后不能换。如果保存时提示"运行在你修改期间有了变化"，点 **载入最新** 看看现在的内容，再重新修改。

## 七、抽查和重做 Agent 确认的任务

自主模式下，子 Agent 做完一个任务后，会逐条检查清单，写出每一条的检查依据（检查了哪个文件、怎么验证的、结果如何），然后自己确认完成。完成记录里会标明 **由 Agent 确认**，以及是哪个模型确认的、每一条的依据。

你可以随时抽查：

1. 在图谱里点开标着「Agent 完成」的任务；
2. 在「任务文件」里看提交的文件，展开「已提交文件与完成记录」看每一条的检查依据；
3. 不满意的话，点 **继续修改**。任务回到可以修改的状态，用到它结果的下游任务会进入"待复核"，和平时一样。你可以自己改，也可以在任务对话里告诉 Agent 怎么改。

你也可以在运行中自己动手完成任何任务，和平时一样。

## 八、预算

每次运行都有上限，任何一项用完，运行会暂停并等你处理：

| 设置 | 默认值 | 意思 |
| --- | --- | --- |
| 同时工作的子 Agent | 3 | 最多几个子 Agent 同时做各自的任务 |
| 同时开的虚拟机 | 2 | 这次运行最多同时占用几台虚拟机。到上限后不会暂停，只是 Agent 不能再开新的 |
| 最长运行时间（小时） | 8 | 暂停期间不计时 |
| 折算 token 预算（万） | 2000 | 总 Agent 和全部子 Agent 一共能用多少，按下面说的“折算 token”计算 |
| 总 Agent 最多轮数 | 200 | 总 Agent 每想一轮算一轮 |

### 什么是折算 token

Agent 每想一步，都要把这个对话到目前为止的内容重新读一遍。重读的旧内容叫**缓存读取**，价格比新内容便宜得多（通常只有一成左右）。如果把它和新内容一样算，一个查了很多资料的子 Agent 几分钟就能把预算用完，而实际花的钱并不多。

所以预算按**折算 token** 计算：新输入的内容、模型写出的内容全额计算，缓存读取只按一定比例计算，默认 10%。比例在「高级」里可以改：填 100 就是全额计算。运行中改了比例，已经用掉的部分会立刻按新比例重算。

**怎么估预算**：Agent 每想一步的折算量，大约是“这一步新增的内容 + 已有对话长度 × 10%”。一个子 Agent 的对话一般会控制在 12 万 token 以内（太长时系统会自动把前面的部分整理成摘要），所以每一步大约一万折算 token 上下。一个要做四五十步的任务，大约四五十万；默认的 2000 万够几十个这样的任务。真正用了多少，看运行面板的预算用量。

### 其他设置

「高级」里还有四项：前三项决定什么时候认为子 Agent 卡住、停下来等你，最后一项是上面说的缓存读取比例：

| 设置 | 默认值 |
| --- | --- |
| 催促同一个子 Agent 的次数 | 10 |
| 连续失败几次算卡住 | 5 |
| 连续几轮没进展算卡住 | 3 |
| 缓存读取计入预算的比例（%） | 10 |

**改默认值**：点左下角 **模型配置**，往下找到 **自主模式默认值**，改好后点 **保存默认值**。以后启动的运行会预填这些值；正在进行的运行不受影响，要改它的预算，在它的运行面板里点「修改目标、模型和预算」。如果提示别的页面刚改过，点 **重新读取** 后再改。

## 九、哪些事 Agent 不能做

下面这些只能由你在页面上操作，自主模式下也一样：

- 删除任务、清空任务进展；
- 永久删除虚拟机；
- 删除项目。

Agent 需要做这些事时，会在对话里请你来做（显示为"需要你处理"）。

## 十、常见问题

- **按钮一直显示"等待你处理"**：打开运行面板，看「需要你处理」里还有哪几件事。
- **子 Agent 看不到虚拟机画面**：它用的模型不支持图片。在运行面板里点「修改目标、模型和预算」，在「总 Agent 还可以给个别任务换用」里勾选一个支持图片的模型（或把子 Agent 默认模型换成支持图片的），保存后总 Agent 就可以给需要的任务换用，不用停止运行。
- **运行结束后想再做一次**：点右上角 **自主模式**，可以重新启动；窗口顶部能打开上次运行的记录。
- **想知道 Agent 为什么这么做**：打开总 Agent 或子 Agent 的对话，里面有完整的过程。
